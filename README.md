# RollerSoccer France

Portail vitrine consacré au RollerSoccer en France : présentation de la discipline, catégories, développement des clubs, médias, palmarès récent et points de contact.

## Développement

```bash
npm install
npm start
```

Puis ouvrir `http://localhost:4200`.

## Build

```bash
npm run build
```

Le projet est une application Angular autonome, sans dépendance au projet `calendrierRollerSoccer`.
