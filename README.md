# RollerSoccer France

Portail vitrine consacré au RollerSoccer en France : présentation de la discipline, catégories, développement des clubs, médias, palmarès récent et points de contact.

## Développement

```bash
npm install
npm start
```

Puis ouvrir `http://localhost:4200`.

## Build

```bash
npm run build
```

## V2

La V2 ajoute notamment :

- une section « Où jouer ? » avec carte indicative des pôles cités dans la saison récente ;
- un parcours clair pour lancer une nouvelle section ou équipe ;
- une section de structuration récente de la discipline ;
- davantage de contenus vidéo et d'accès aux chaînes qui diffusent des matchs ;
- le contact officiel de la commission RollerSoccer FFRS ;
- un palmarès récent conservant les appellations de catégories de chaque saison.

## Sources éditoriales principales

- Règlement sportif RollerSoccer FFRS 2026-2027 fourni au projet ;
- pages RollerSoccer et contacts de la Fédération Française de Roller & Skateboard ;
- bilan FFRS de la saison 2024-2025 ;
- état des lieux RollerSoccer France publié en avril 2026 sur rollerenligne.com ;
- sites publics des clubs pour les liens de mise en relation.

Le projet est une application Angular autonome, sans dépendance au projet `calendrierRollerSoccer`.
